# 🍪 Flavortown Wishlist

A modern web application for managing your Flavortown store wishlist. Browse available products, filter by various criteria, and track how many cookies you need for your dream items.

🌐 **Live Demo**: [flavortown.matejryslavy.dev](https://flavortown.matejryslavy.dev)

![Flavortown Wishlist](screenshot.png)

## ✨ Features

- 🔐 **Secure Login** – authentication via User ID and API key
- 🔍 **Advanced Search** – full-text search across product names and descriptions
- 💰 **Price Filter** – adjustable price range with slider (0-5000 cookies)
- 🏷️ **Sorting Options** – sort by name (A-Z, Z-A) or price (ascending/descending)
- ⭐ **Limited Items Filter** – show only limited edition products
- 🎁 **Wishlist Management** – add/remove items with one click
- 📊 **Budget Tracker** – real-time calculation of total cookies needed
- 📱 **Responsive Design** – works perfectly on desktop, tablet, and mobile

## 🚀 How to Use

1. **Visit** [flavortown.matejryslavy.dev](https://flavortown.matejryslavy.dev)

2. **Login**
   - Enter your Flavortown User ID
   - Enter your API key (get it from [Flavortown](https://flavortown.hackclub.com))
   - Click "Login"

3. **Browse Products**
   - Use the search box to find specific items
   - Adjust the price slider to filter by budget
   - Sort products by name or price
   - Check "Limited only" to see exclusive items

4. **Build Your Wishlist**
   - Click "Add to wishlist" on any product
   - See instant budget calculations
   - Remove items by clicking the × button
   - Track the difference between what you have and what you need

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **API**: Flavortown REST API
- **Storage**: localStorage for login persistence
